King-CrackX

面向授权渗透测试与前端安全评估的 Chrome / Chromium 扩展（Manifest V3）。 自动识别目标站点的 Vue / React 框架、枚举全部路由并生成可访问的完整 URL、绕过前端路由守卫、 从源码与真实请求中提取 API 端点，并基于分析结果自动执行安全审计、导出 Markdown 报告。

下载扩展包 GitHub 仓库

■ 功能特性

框架与版本检测

自动识别 Vue（2 / 3）与 React（17 / 18 / 19）并输出版本号，兼容延迟挂载的 SPA。

路由枚举 · 完整 URL

按 Hash / History 模式与基础路径生成可点击的完整 URL 列表，无法静态枚举时以页面锚点兜底。

梭哈模式 · 绕过守卫

document_start 抢跑强制接管 Router，清除守卫并拦截跳转，按站点白名单生效。

API 端点提取

汇总真实请求、JS 源码静态提取与 Sourcemap 探测三类数据，标注未调用端点，可复制或导出。

安全审计报告

检测敏感 API、裸露路由与 Sourcemap 泄露，生成风险评级与修复建议，导出综合 Markdown 报告。

多主题 · 结果缓存

浅色 / 深色 / 跟随系统 / 极客四种主题；按 URL 缓存分析结果，重复打开秒出。

■ 支持的路由方案

  • Vue Router —— 兼容 v2 / v3 / v4
  • React Router —— data router（v6.4+ / v7）与声明式（v4–v7）
  • TanStack Router —— 优先读取 state.routes，回退路由表
  • Next.js —— Pages Router 枚举组件键，App Router 尽力探测

■ 安装

从 Releases 下载扩展包并解压，或使用源码构建：

# 构建产物位于 dist/
npm install --include=dev
npm run build

打开 chrome://extensions/，开启开发者模式，点击「加载已解压的扩展程序」，选择解压后的目录即可。

■ 使用

① 分析
打开目标页面点击扩展图标，自动识别框架并分析路由。
② 访问
在完整 URL 列表中复制或打开目标路由。
③ 绕过
需要绕过守卫时开启梭哈模式并刷新（仅当前站点生效）。
④ 提取
点击「提取 API」获取端点清单，可复制或导出。
⑤ 审计
在安全审计面板点击「开始审计」，导出整合全模块的 Markdown 报告。

■ 工作原理

扩展同时运行在三个 JavaScript 世界（扩展后台 / 内容脚本 ISOLATED / 页面主世界 MAIN），content.ts 作为传话筒桥接 chrome.* 与页面框架内部对象。详见仓库内文档 整体架构：三世界模型。
